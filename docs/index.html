Processing Pipeline

Three-stage audio intelligence — from raw waveform to verified transcript.

🎙️
01

Audio Ingestion

Load WAV / MP3 via Silero's read_audio or soundfile fallback. Resamples to 16 kHz mono automatically.

→
📊
02

Silero VAD

Speech timestamps with configurable thresholds — 250 ms min speech, 400 ms silence gap, 150 ms padding, 20 s max clip duration.

→
📝
03

SraVaani ASR

Each segment transcribed using ARTPARK-IISc/SraVaani-1.0 with torch.inference_mode(). Supports 20+ low-resource languages.

→
👥
04

pyannote Diarization

Detect speaker turns and split segments where multiple people talk, tagging each with Speaker 1 / Speaker 2.

Capabilities

Built for Real-World Audio

Every component tuned for low-resource language work on commodity hardware.

⎍

Silero VAD Engine

Pre-trained voice activity detection with 0.5 threshold, minimum speech duration of 250 ms, and 150 ms speech padding for clean segment boundaries.

threshold=0.5, min_speech_duration_ms=250
🗣️

SraVaani Transcription

Multilingual ASR from ARTPARK-IISc supporting 20+ low-resource languages and regional variants. CPU & GPU compatible.

model.transcribe(path, return_hypotheses=True)
📦

Batch Processing

Process multiple audio files in a single run. Failed clips don't halt the batch — resilient pipeline with per-file output directories.

python main.py "a.wav" "b.mp3" "c.wav"
📄

Structured Output

Each file produces segments.csv with timestamps and transcriptions.csv with ASR drafts and a verified column for human review.

segments/<stem>/segment_00001.wav
⚡

Thread Optimization

VAD runs single-threaded for determinism. ASR restores 4 threads for throughput. No thread contention between stages.

VAD_THREADS=1 → ASR_THREADS=4
🌐

Setup Pipeline
Recommended: awadhi_transcription

Standard pipeline defaults are active. Enable exception mode only to apply parameter overrides for edge-case audio.

threshold default: 0.5
min_speech_ms default: 250
min_silence_ms default: 400
speech_pad_ms default: 150
max_speech_s default: 20
sample_rate fixed: 16k
💡

Environment Note: VAD exception parameters apply across all modes. For neural ASR transcription (SraVaani / Whisper / PyAnnote), launch SegAUD in PC App mode (run_segaud.bat) or Terminal mode.

Generated Configuration

segaud_config.py 
# SegAUD Project Configuration
# Generated for: awadhi_transcription

PROJECT_NAME    = "awadhi_transcription"
TARGET_LANG     = "awa"  # Awadhi

# ── VAD Settings ──
SAMPLE_RATE     = 16000
VAD_EXCEPTIONS  = None  # Uses standard defaults

# ── ASR Settings ──
ASR_ENGINE      = "sravaani"
ASR_MODEL       = "ARTPARK-IISc/SraVaani-1.0"
ASR_THREADS     = 4
DEVICE          = "auto"  # cuda if available

# ── Output ──
OUTPUT_DIR      = "segments"
CSV_ENCODING    = "utf-8-sig"

Execution Environments

Model Compatibility Guide

Some lightweight processing runs directly in the website browser, while deep neural models require PC App mode or Terminal mode after local weights download.

🌐
Web Browser Mode Client Sandbox

Runs inside standard web browsers via Web Audio API. Zero install required.

Works in Browser: Silero VAD (In-browser) Audio Playback Table CSV Review
⚠️ Multi-gigabyte neural PyTorch models (Whisper, SraVaani, PyAnnote) cannot execute inside raw client browser tabs.
💻
PC Desktop App Mode Recommended

Launched via run_segaud.bat or python app.py. Full local PyTorch engine runs on your PC CPU/GPU.

Full Neural Inference: OpenAI Whisper-Base / Small ARTPARK SraVaani-1.0 pyannote Diarization Any Hugging Face Model
✓ Weights automatically downloaded to local Hugging Face cache on first run; slices saved directly to disk.
⌨️
Terminal / CLI Mode Headless / Batch

Run batch pipelines directly: python main.py audio.wav --domain Agriculture.

Ideal For: Multi-Hour Recordings Folder Batch Processing Script Automation
⚡ Maximum multi-threading throughput with zero UI overhead.
